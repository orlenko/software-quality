# Software Quality

A shared development standard and a versioned quality runner for humans and coding agents.

This repository currently contains the handoff and candidate design. The CLI, package, agent commands, and releases have not been implemented.

## Start here

```sh
git clone https://github.com/orlenko/software-quality.git
cd software-quality
```

Read [AGENTS.md](AGENTS.md), then [HANDOFF.md](HANDOFF.md). The candidate [development standard](docs/development-standard.md) and [toolkit design](docs/toolkit-design.md) describe the intended behavior.

## Install and verify

There is no runtime package to install or test command yet. The first implementation must document its prerequisites, safe test command, and verification results here.
